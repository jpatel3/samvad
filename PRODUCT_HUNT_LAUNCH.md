# Samvad — Product Hunt Launch Copy

## Tagline (60 char max)
**Read Hindu scriptures in 10 minutes a day**

## Short Description
Samvad is a daily spiritual reading app for the Vachanamrut and Bhagavad Gita. Each scripture is broken into focused 10-minute readings with interactive quizzes, streak tracking, and support for English, Gujarati, and Hindi.

## Full Description

### The Problem
Hindu scriptures like the Vachanamrut (262 discourses) and Bhagavad Gita (700 verses) are rich but dense. Most people want to study them consistently but don't know where to start, lose track of where they left off, or can't commit large blocks of time.

### What Samvad Does
Samvad structures these scriptures into bite-sized daily readings — each takes about 10 minutes. After reading, you take a short quiz to test your understanding, earn XP, and build a daily streak.

### Key Features
- **Two scriptures** — Vachanamrut (262 discourses, ~330 readings) and Bhagavad Gita (18 chapters, 71 readings)
- **10-minute daily readings** — Dialogue format preserving the original question-answer structure
- **Interactive quizzes** — True/False and multiple-choice questions after each reading
- **Streak tracking** — Daily streaks with freezes and milestone celebrations
- **Three languages** — English, Gujarati, and Hindi
- **Listen along** — Text-to-speech with real-time highlighting
- **Progress tracking** — Per-scripture progress with XP system
- **Works everywhere** — Web app + iOS (via TestFlight, App Store coming soon)

### Built With
React (web), React Native / Expo (mobile), Zustand for state management, Tailwind CSS. No backend — everything runs locally in your browser or on your device.
